# 13. AI-GENERATED IMAGE PLAN

Because you want AI-generated visuals, the safest approach is to generate **brand-supporting images** and **concept visuals**, while avoiding misleading fake claims.

## Important rules before generating images

### DO generate
- architectural / structural hero visuals
- abstracted engineering imagery
- concept project renders
- BIM-inspired visuals
- technical texture backgrounds
- blueprint / line-art visual assets
- site atmosphere images
- structural detail close-ups
- editorial case-study visuals

### DO NOT generate as if real
- fake client logos
- fake certification badges
- fake real-life team photos presented as real employees
- fake signed drawings with real project names
- fake awards
- fake testimonial headshots and quotes
- fake partner logos
- fake office photos pretending to be your real office
- fake completed projects presented as actual delivered work unless labeled as concept

If an image is illustrative only, label it like:
- **Concept Visual**
- **Representative Visual**
- **Illustrative Rendering**
- **Sample Visualization**

---

### 1. Hero image
**Purpose:** Main homepage visual

**Look:** modern reinforced-concrete building, structural expression, dramatic but realistic, premium editorial mood

**Purpose:** Support About section  
**Type:** Interior technical office / engineers reviewing drawings / BIM-focused workspace

Create one for each service:
- structural coordination
- reinforcement BIM detailing

- BBS / quantity outputs
- fabrication support

**Look:** each image should feel technical and purposeful, not stock-photo corporate.

### 4. Project showcase images
**Purpose:** Portfolio previews  
**Type:** high-end conceptual construction / structural project visuals  
**Suggested sectors:**
- high-rise residential
- mixed-use development
- hospital / healthcare facility
- commercial complex
- educational campus
- infrastructure / podium / parking structure

Use them as representative visuals unless tied to real projects.

### 5. BIM / model imagery
**Purpose:** Samples and process sections  
**Type:** clean 3D model views, exploded structure diagrams, reinforcement model screenshots, annotated model perspectives  
**Style:** realistic BIM-like visualization, white / grey / steel tones with restrained accent color

### 6. Technical drawing visuals
**Purpose:** Samples section, backgrounds, dividers  
**Type:** blueprint lines, rebar detailing sheets, section cuts, callouts, bar marks, schedule fragments  
**Style:** clean, engineered, crisp, high-resolution

### 7. Process visuals
**Purpose:** Show workflow steps  
**Type:** minimal diagram assets or background visuals for each process stage  
Possible stages:
- design package intake
- coordination review
- BIM detailing
- drawing production
- QA review
- final delivery

### 8. CTA / contact image
**Purpose:** Final contact section  
**Type:** premium architectural detail, dusk facade, concrete/steel close-up, or subtle technical image  
**Goal:** end the page with a calm, serious, premium visual tone

### 9. Blog / insight cover images
**Purpose:** Article thumbnails  
**Type:** abstract engineering scenes, structural details, blueprint overlays, BIM visuals

### 10. Texture / graphic background assets
**Purpose:** enrich layout without slop  
**Type:** subtle line grids, technical diagram crops, paper textures, faint blueprint overlays, datum lines, measurement fragments
